## 🛠️ Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AhmadTibyanHakim77/PORTOFOLIA-HXQ.git
```

**2. Navigate to the project directory**

```bash
cd PORTOFOLIA-HXQ
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open your browser**

```text
http://localhost:3000
```
